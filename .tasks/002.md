Every command beyond the core's own (help, version, list) is a separate part, and a machine's commands are whichever parts it has. Each part carries a one-line description, so clv help can say what a person can do here.

On record: the mini's tools are already separate files (clv-login, clv-stamp, clv-tmux), and his launcher already treats each short command as a file. Levi's question on the org board applies here too: "How will they know they have them?" Which of the five keep the name is Levi's call.

Looking from the folder you are in, clv walks up the parent folders, then the person's own, then the machine-wide ones, and the nearest wins.

On record: a working form runs on the mini, where clv env prints six scopes (global, creds, env, org, user, dir). The order "global, environment, user, directory" and "read upward, write to the narrowest" were drafted by Claude 8/12 (org-harness T33, prep pack D5) and are not ruled. T33 carries one constraint: walk up on local disk only, never inside a Drive folder.

Done when: from a nested folder, clv finds a command or a setting kept in a parent folder, the nearest one wins, and clv can say where each was found.

Intent: canon 56: "Settings are stored in the file directory and resolved per-context by walking up to parent folders until the setting is found."

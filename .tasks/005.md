Looking from the folder you are in, clv walks up the parent folders, then the person's own, then the machine-wide ones, and the nearest wins. Canon 56 is the rule. The order "global, environment, user, directory" and "read upward, write to the narrowest" were drafted by Claude 8/12 (org-harness T33, prep pack D5) and are not ruled. T33 carries one constraint: walk up on local disk only, never inside a Drive folder.

Intent: canon 56: "Settings are stored in the file directory and resolved per-context by walking up to parent folders until the setting is found."
